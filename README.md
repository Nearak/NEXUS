# NEXUS-7

لعبة تحقيق سيبراني عربية تعمل بالكامل داخل المتصفح. يتقمص اللاعب دور المشغّل «راصد» ويحل ثلاث ليالٍ مترابطة باستخدام الطرفية، شبكة NET-3D المجسّمة، مختبر الأدلة، قاعدة البيانات، مِرقاب، وLYNX.

تعرض المهمات كمراحل تشغيلية متسلسلة؛ كل مرحلة تفتح التالية بعد تحقق المحرك من النتيجة الفعلية للأداة. تعرض بطاقة المهمة فحوصاتها الجزئية بوضوح، وتعيد الأوامر المنفذة سابقًا مزامنة الحقائق عند التكرار أو استعادة الجلسة. أصبحت **NET-3D** واجهة الشبكة الوحيدة، مع نماذج مختلفة للمحطة والبوابة والجسر والكاميرا.

تضيف الليلة الأولى مسار تحقيق أدق: تنزيل سجل العبور واللقطة، استخراج لوحة المركبة عبر **ANALYZER** مع توثيق المصدر، ثم مطابقة اللوحة مع السجل المدني قبل فتح ملف القضية.

في الليلة الثانية أصبح **MIRQAB** خط تحليل متكاملًا: ضبط الحامل الأول، تثليث الموقع بين القطاعات، التقاط القناة المرافقة، ثم فصل الحزمة واستخراج شهادة صوتية. أما الليلة الثالثة فأصبح المتصفح مساحة تحقيق فعلية تتضمن أرشفة المصادر، فحص الراوتر، عزل الجلسة، وتثبيت الرسالة قبل ربط الأدلة.

بعد تسليم التقرير تبقى رسائل المشرف ظاهرة، ويبدأ الانتقال فقط عند الضغط على «ابدأ الليلة التالية». كما يمكن استئناف انتقال انقطع بسبب تحديث الصفحة، ويعمل زر إعادة التشغيل سواء كانت نهاية الليلة محفوظة كـ«مكتملة» أو «انتقال جارٍ».

## التشغيل

شغّل خادم ملفات محليًا من مجلد المشروع، ثم افتح العنوان الذي يظهر في الطرفية:

```bash
python -m http.server 8000
```

التقدم والهوية والملاحظات تُحفظ محليًا في المتصفح.

## الاختبارات

```bash
node --test tests/logic-smoke.test.js
```

تغطي الاختبارات تقدم الأهداف وتسلسل المراحل، مزامنة `connect` والأوامر المكررة، حفظ تحليل اللقطة، فتح إرسال التقرير، أهداف الليلة الثانية، استعادة تسلسل مِرقاب، ومنع تعطل المحرك عند غياب Three.js.

## اختصارات مفيدة

- `Alt+M`: عرض المهمة الحالية.
- `Esc`: إغلاق النافذة أو اللوحة المفتوحة.
- `Tab`: إكمال أوامر الطرفية.
